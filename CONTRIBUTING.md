# Contributing

Thank you for trying this early project. Report bugs with the browser version, steps to reproduce, and the expected and actual behavior. Use synthetic filenames or a minimal example instead of uploading confidential papers.

For a code change, keep the offline behavior intact, use no remote assets, and run `node --test`. Add a regression test for a reproducible logic bug. Test browser behavior with local files before proposing the change.

Useful first improvements: editable metadata, pagination for large libraries, an English UI, and clearer handling of files that cannot be hashed. Discuss larger changes before implementing them.
